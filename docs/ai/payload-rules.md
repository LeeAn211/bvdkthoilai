# Payload CMS Rules

- Reuse existing Collections/Globals.
- Check current fields before adding new ones.
- Do not delete/rename data-bearing fields without a preservation plan.
- Prefer CMS-managed content over hard-coded frontend content.
- Keep PostgreSQL dbName values short.
- After schema edits run generate:types, generate:importmap, and typecheck.
- Avoid duplicate components/collections for existing functionality.
