# Regression Checklist

For changes affecting shared UI, navigation, multiple components, or schemas, check the affected subset of:
- homepage
- header/menu/dropdowns
- mobile layout
- Payload Admin
- public detail route
- CMS data rendering
- images/media
- generated Payload types/import map
- TypeScript
- routes sharing the same component

Use targeted checks; do not run every check for every small change.
